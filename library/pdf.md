# Library PDF Catalogue

**Last updated: 2026-09-26**

## What this file is

657 PDFs live in `library/`. This file records which are _in-system_ (the
subject maps to a question pack we have built) versus _extra_ (download-only;
we keep them for reference but have no question pack for that subject).

### Status legend

| Status | Meaning |
|---|---|
| ✅ questions imported | Past-paper JS file exists in `subjects/.../questions/past_paper_YYYY.js` |
| 📄 no questions yet | Subject matches our pack but nothing imported — future source material |
| 🗂️ extra | No matching pack; PDF is for download only |

## What is NOT in the library

No PDFs exist for **Grades 1–3**. There are no official public exam papers
for those grades — the library only holds grade 4+ papers and MIE resources.

We have packs for grades 1–3 (Maths, English, French, Health, and for
Grade 3: SSEE) but those questions were written from scratch against the
MIE curriculum, not sourced from past papers.
