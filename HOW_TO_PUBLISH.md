# How to Publish MathMaster Online

## PART 1 — Host the website (Netlify) — Free, takes 5 minutes

### Step 1 — Create a Netlify account
1. Go to **https://netlify.com**
2. Click **Sign up** → choose **Email** (or sign in with GitHub)
3. Verify your email

### Step 2 — Deploy the site
1. Log in to Netlify
2. On the dashboard, find the big box that says **"Drag and drop your site folder here"**
3. Open File Explorer and find the `shanvi` folder on your Desktop
4. **Drag the entire `shanvi` folder** into that Netlify box
5. Wait ~10 seconds — Netlify uploads and builds everything
6. You will get a URL like: `https://random-name-12345.netlify.app`
   - This URL works on any device, anywhere in the world
   - Students can open it on their phones or tablets

### Step 3 — Give it a custom name (optional)
1. In Netlify, go to **Site configuration → Change site name**
2. Type something like `mathmaster-shanvi`
3. Your URL becomes: `https://mathmaster-shanvi.netlify.app`

### Step 4 — Update the site later
Whenever you make changes to the files:
1. Go to **Netlify → Deploys**
2. Drag the updated `shanvi` folder again
3. New version goes live in ~10 seconds

## PART 2 — Add a backend / protect data (Supabase) — Do this LATER

> Skip this section for now. Do it when you are ready to add real accounts and cross-device progress saving.

### What Supabase gives you
- Students log in with email + password (not just a name)
- Progress is saved in a real database — not lost if they clear the browser
- Teachers can see results automatically (no result codes needed)
- Works on any device — student logs in on phone, sees same progress on tablet

### Step 1 — Create a Supabase account
1. Go to **https://supabase.com**
2. Click **Start your project** → sign up with GitHub or Email
3. Create a new **Project** (choose any region close to Mauritius, e.g. `eu-central-1`)
4. Wait ~2 minutes for the project to start

### Step 2 — Create the database table
1. In your Supabase project, click **SQL Editor** in the left menu
2. Paste the SQL below and click **Run**:

```sql
-- Students table
create table students (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users(id) on delete cascade,
  name text not null,
  avatar text default '🧒',
  stats jsonb default '{"totalAttempted":0,"totalCorrect":0,"examCount":0,"bestScore":0,"maxStreak":0,"streak":0,"lastDate":null}'::jsonb,
  chapters jsonb default '{}'::jsonb,
  exam_history jsonb default '[]'::jsonb,
  badges jsonb default '[]'::jsonb,
  theme text default 'light',
  xp integer default 0,
  level integer default 1,
  assignments jsonb default '[]'::jsonb,
  restrictions jsonb default '{"lockedChapters":[],"maxDifficulty":4,"examDisabled":false}'::jsonb,
  created_at timestamptz default now()
);

-- Row level security — each student only sees their own data
alter table students enable row level security;
create policy "students can read own data" on students for select using (auth.uid() = user_id);
create policy "students can write own data" on students for all using (auth.uid() = user_id);
```

### Step 3 — Get your connection keys
1. In Supabase, go to **Settings → API**
2. Copy the two values:
   - **Project URL** — looks like `https://abcdefgh.supabase.co`
   - **anon (public) key** — a long string starting with `eyJ...`
3. Tell Claude Code: *"I'm ready to connect Supabase — here are my keys"*
4. Claude will create a `config.js` file and update `engine/store.js` for you

### Step 4 — Redeploy to Netlify
After Claude updates the files, drag the `shanvi` folder to Netlify again.

## PART 3 — Custom domain (optional, costs ~$10/year)

If you want `www.mathmaster.mu` or similar instead of `.netlify.app`:
1. Buy a domain at **Namecheap** or **GoDaddy**
2. In Netlify → **Domain management → Add custom domain**
3. Follow their 3-step DNS instructions (takes ~1 hour to activate)
